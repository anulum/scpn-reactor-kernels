# Support

## Getting help

- **Documentation.** Start with [`README.md`](README.md),
  [`ARCHITECTURE.md`](ARCHITECTURE.md) for the boundary this repository owns,
  and [`VALIDATION.md`](VALIDATION.md) for what each capability's evidence
  actually is.
- **Bug reports.** [Open an issue](https://github.com/anulum/scpn-reactor-kernels/issues/new?template=bug_report.yml).
  Include what you expected, what happened, and the commit you were on.
- **Feature requests.** [Open an issue](https://github.com/anulum/scpn-reactor-kernels/issues/new?template=feature_request.yml).
- **Questions, and pointers to sources.**
  [Discussions](https://github.com/anulum/scpn-reactor-kernels/discussions). If you can point to a
  freely available version of a work this repository cites but cannot obtain,
  that is the most useful thing anyone outside can contribute.
- **Direct contact.** <protoscience@anulum.li>

## Security

Do not report security issues in public. Use
[Security Advisories](https://github.com/anulum/scpn-reactor-kernels/security/advisories/new) or
<protoscience@anulum.li>, and see [`SECURITY.md`](SECURITY.md).
