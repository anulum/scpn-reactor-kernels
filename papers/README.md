# Papers

This directory is the canonical public home for manuscript artefacts of
SCPN-REACTOR-KERNELS. Submission packages live under
[`submissions/`](submissions/) as self-contained directories with stable
three-digit ordering prefixes (`001_descriptive_name`).

No submission package exists yet. Each future package keeps its
manuscript source, bibliography, figures, build instructions, citation
metadata, and the generated review PDF together, and must rebuild from a
clean checkout with a documented toolchain. A package directory is a
review workspace, not evidence that a manuscript has been submitted or
accepted.
